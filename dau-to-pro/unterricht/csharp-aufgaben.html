Datenkonvertierung I implizit & explizit

Aufgabe 1 int → double

Erstelle eine Variable vom Typ int und weise ihr einen Wert zu. Erstelle anschließend eine Variable vom Typ double und weise ihr die int-Variable zu.

Implizite Konvertierung – kein Datenverlust, daher kein Cast nötig.
Lösung anzeigen 
int zahl = 42;
double kommazahl = zahl;   // implizit

Console.WriteLine(kommazahl); // 42

Aufgabe 2 double → int

Erstelle eine Variable vom Typ double und weise ihr einen Wert zu. Erstelle anschließend eine Variable vom Typ int und konvertiere den double-Wert explizit in int.

Expliziter Cast (int) – die Nachkommastellen werden abgeschnitten, nicht gerundet.
Lösung anzeigen 
double preis = 19.99;
int ganzzahl = (int)preis;   // explizit

Console.WriteLine(ganzzahl); // 19

Aufgabe 3 long ↔ float

Konvertiere long explizit in float und konvertiere float explizit in long.

long → float wäre auch implizit möglich, kann aber an Genauigkeit verlieren. float → long schneidet die Nachkommastellen ab.
Lösung anzeigen 
long grosseZahl = 123456789L;
float f = (float)grosseZahl;
Console.WriteLine(f);        // 1,2345679E+08 (Genauigkeit geht verloren)

float wert = 987.65f;
long l = (long)wert;
Console.WriteLine(l);        // 987

Aufgabe 4 double → int & float

Erstelle eine Variable vom Typ double, weise ihr einen Wert zu, und konvertiere diesen Wert explizit sowohl in int als auch in float.

Lösung anzeigen 
double d = 3.14159265359;

int   i = (int)d;
float f = (float)d;

Console.WriteLine($"double: {d}");  // 3,14159265359
Console.WriteLine($"int:    {i}");  // 3
Console.WriteLine($"float:  {f}");  // 3,1415927

Datenkonvertierung II Benutzereingaben

Währungsumrechner

Aufgabe: Schreibe ein Programm, das einen Betrag in Euro einliest und in US-Dollar umrechnet.

Kurs: 1 Euro = 1,1 US-Dollar

EingabeAusgabe
Betrag in EuroBetrag in US-Dollar
Lösung anzeigen 
const double Kurs = 1.1;

Console.Write("Betrag in Euro: ");
double euro = Convert.ToDouble(Console.ReadLine());

double dollar = euro * Kurs;

Console.WriteLine($"{euro:F2} € = {dollar:F2} $");

Temperaturkonvertierung

Aufgabe: Erstelle ein Programm, das eine Temperatur in Celsius von der Konsole einliest und in Fahrenheit umrechnet.

Formel: F = C × 9 / 5 + 32

Anforderungen:

  • Frage den Benutzer nach einer Temperatur in Celsius
  • Konvertiere den eingegebenen Wert von string zu int oder double
  • Berechne die Temperatur in Fahrenheit
  • Gib die umgerechnete Temperatur in Fahrenheit in der Konsole aus
Verwende Convert.ToDouble() oder Convert.ToInt32() zum Konvertieren der Benutzereingabe.
Lösung anzeigen 
Console.Write("Temperatur in Celsius: ");
double celsius = Convert.ToDouble(Console.ReadLine());

double fahrenheit = celsius * 9 / 5.0 + 32;

Console.WriteLine($"{celsius} °C = {fahrenheit} °F");

Altersumrechnung

Aufgabe: Erstelle ein Programm, das das Alter eines Benutzers in Jahren einliest und in Monate umrechnet.

Formel: Monate = Jahre × 12

Anforderungen:

  • Frage den Benutzer nach seinem Alter in Jahren
  • Konvertiere den eingegebenen Wert von string zu int
  • Berechne das Alter in Monaten (1 Jahr = 12 Monate)
  • Gib das umgerechnete Alter in Monaten in der Konsole aus
Verwende Convert.ToInt32() zum Konvertieren der Benutzereingabe.
Lösung anzeigen 
Console.Write("Dein Alter in Jahren: ");
int jahre = Convert.ToInt32(Console.ReadLine());

int monate = jahre * 12;

Console.WriteLine($"Du bist {monate} Monate alt.");

If-Bedingung if / else

Aufgabe 1 Benutzer-Login-System

Erstelle ein Login-System, in dem sich der Benutzer zuerst registrieren und dann einloggen kann.

Das Programm soll beim Login prüfen, ob Benutzername und Passwort mit denen der Registrierung übereinstimmen.

Da das Speichern von Daten noch nicht behandelt wurde, erfolgen Registrierung und Login in derselben Programmausführung.

Verwende if-Anweisungen, Benutzereingaben und Methoden. (if-else)
Lösung anzeigen 
class Program
{
    static string gespeicherterName;
    static string gespeichertesPasswort;

    static void Main()
    {
        Registrieren();
        Einloggen();
    }

    static void Registrieren()
    {
        Console.WriteLine("=== Registrierung ===");
        Console.Write("Benutzername: ");
        gespeicherterName = Console.ReadLine();
        Console.Write("Passwort: ");
        gespeichertesPasswort = Console.ReadLine();
        Console.WriteLine("Registrierung erfolgreich!\n");
    }

    static void Einloggen()
    {
        Console.WriteLine("=== Login ===");
        Console.Write("Benutzername: ");
        string name = Console.ReadLine();
        Console.Write("Passwort: ");
        string passwort = Console.ReadLine();

        if (name == gespeicherterName && passwort == gespeichertesPasswort)
        {
            Console.WriteLine($"Login erfolgreich. Willkommen, {name}!");
        }
        else
        {
            Console.WriteLine("Benutzername oder Passwort falsch.");
        }
    }
}

Aufgabe 2 Hotel – Aufschlag bei einer Übernachtung

Schreibe ein Programm, das einen Aufschlag (z. B. 20 €) berechnet, wenn der Gast nur einen Tag im Hotel übernachtet.

Verarbeitungsschritte:

  1. Nettobetrag = Zimmerpreis × Aufenthaltsdauer × Anzahl der Personen
    → wird immer ausgeführt
  2. Wenn Aufenthaltsdauer = 1 → Nettobetrag + 20 €
    → wird nur ausgeführt, wenn die Bedingung zutrifft

Variablen:

NameBedeutung
Zimmerpreis70 (fest)
AnzahlDerPersonenAnzahl der Gäste
AufenthaltsdauerAnzahl der Nächte
MwstMehrwertsteuer
NettopreisPreis ohne MwSt.
GesamtpreisPreis inkl. MwSt.
EingabeAufenthaltsdauerBenutzereingabe (string)
EingabeAnzahlDerPersonBenutzereingabe (string)
Lösung anzeigen 
double Zimmerpreis = 70;
double Mwst = 0.19;   // Übung: 19 % (real für Übernachtungen: 7 %)
double Aufschlag = 20;

Console.Write("Aufenthaltsdauer (Nächte): ");
string EingabeAufenthaltsdauer = Console.ReadLine();
int Aufenthaltsdauer = Convert.ToInt32(EingabeAufenthaltsdauer);

Console.Write("Anzahl der Personen: ");
string EingabeAnzahlDerPerson = Console.ReadLine();
int AnzahlDerPersonen = Convert.ToInt32(EingabeAnzahlDerPerson);

// Schritt 1 – wird immer ausgeführt
double Nettopreis = Zimmerpreis * Aufenthaltsdauer * AnzahlDerPersonen;

// Schritt 2 – nur bei genau einer Übernachtung
if (Aufenthaltsdauer == 1)
{
    Nettopreis = Nettopreis + Aufschlag;
    Console.WriteLine($"Aufschlag für eine Übernachtung: {Aufschlag:F2} €");
}

double Gesamtpreis = Nettopreis * (1 + Mwst);

Console.WriteLine($"Nettopreis:  {Nettopreis:F2} €");
Console.WriteLine($"Gesamtpreis: {Gesamtpreis:F2} €");
