01 / C#

Variablen & Typen

string – Text

string ort = "Büro";

Speichert Text. Text steht in doppelten Anführungszeichen.

int – Ganze Zahl

int minuten = 45;

Speichert ganze Zahlen. 45 ist eine Zahl, "45" ist Text.

double – Kommazahl

double temperatur = 21.5;

Gleitkommazahl. In C# steht ein Punkt als Dezimaltrennzeichen; nicht jede Dezimalzahl ist exakt darstellbar.

bool – Wahrheitswert

bool fertig = false;

Hat zwei mögliche Werte: true und false.

Variable ändern

int minuten = 45;
minuten = 60;
Console.WriteLine(minuten);
60

Der neue Wert ersetzt den alten. Beim Ändern den Typ nicht erneut angeben.

Variable und Text ausgeben

int minuten = 45;
Console.WriteLine(minuten);
Console.WriteLine("minuten");
Console.WriteLine("Minuten: " + minuten);
45 minuten Minuten: 45

Ohne Anführungszeichen wird der Variablenwert ausgegeben. Mit Anführungszeichen steht wörtlicher Text. + verbindet hier Text und Wert.

Merke: Der Variablentyp steht beim Anlegen fest. C# unterscheidet Groß- und Kleinschreibung; die Anweisungen enden mit ;. Eine Zuweisung allein erzeugt keine Ausgabe.
02 / C#

Konsolenbefehle

Console.Write()

Console.Write("Hallo ");
Console.Write("Büro!");
Hallo Büro!

Gibt Text ohne nachfolgenden Zeilenumbruch aus.

Console.WriteLine()

Console.WriteLine("Hallo Büro!");
Console.WriteLine("Nächste Zeile");
Console.WriteLine();
Hallo Büro! Nächste Zeile

Gibt Text mit anschließendem Zeilenumbruch aus. Ohne Argument fügt es einen Zeilenumbruch ein.

Console.ReadLine()

Console.Write("Name: ");
string? name = Console.ReadLine();
Console.WriteLine("Hallo " + name);
Name: Ada Hallo Ada

Liest die gesamte Eingabezeile als Text, ohne Enter-Zeilenumbruch. Nur Enter ergibt leeren Text. string? erlaubt null bei Eingabeende.

Console.Read()

int code = Console.Read();
Console.WriteLine(code);
65 // nach Eingabe von A

Liest den Zeichencode des nächsten Zeichens als int, nicht die eingegebene Zahl. 7 ergibt 55; am Eingabeende folgt -1. Im üblichen Terminal ist Enter nötig.

Unterschied: ReadLine() liest eine ganze Textzeile, Read() einen Zeichencode. WriteLine() wechselt danach die Zeile, Write() nicht.
03 / C#

Typumwandlungen

Implizit: int → double

int anzahl = 7;
double wert = anzahl;

Die Umwandlung erfolgt ohne Cast. wert enthält 7 als double; anzahl bleibt eine int-Variable.

Explizit: double → int

double messwert = 21.9;
int ganz = (int)messwert;
Console.WriteLine(ganz);
21

(int) schneidet Nachkommastellen Richtung 0 ab. Auch -21.9 wird zu -21. Das ist kein Runden; der Wert muss in den int-Bereich passen.

Vor dem Teilen umwandeln

int a = 7, b = 2;
double genau = (double)a / b;       // 3,5
double gekuerzt = (double)(a / b);  // 3

Beim ersten Ausdruck wird vor der Division umgewandelt. Beim zweiten ergibt int / int zuerst 3. Der spätere Cast kann die abgeschnittenen Nachkommastellen nicht zurückholen.

Convert.ToDouble() – Text in Zahl

string text = "12,5";
double zahl = Convert.ToDouble(text);
Console.WriteLine(zahl);
12,5 // bei deutscher Zahlenkultur

Interpretiert Zahlentext als double. Das Dezimaltrennzeichen hängt von der aktuellen Zahlenkultur ab: 12,5 bei de-DE, 12.5 bei en-US. Ungültiger oder leerer Text löst FormatException aus; null wird zu 0. (double)text funktioniert bei string nicht.

Drei Wege: Implizit ohne Cast, explizit mit (Zieltyp) und Textkonvertierung mit Convert.ToDouble(). Der Typ der ursprünglichen Variablen bleibt unverändert.
